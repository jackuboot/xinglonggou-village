# 01 · 需求卡（REQ-PLOT-001）

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 需求编号 | REQ-PLOT-001 |
| 业务域 | 农户资源 |
| 优先级 | P0 |
| 主责角色 | 农户（提交）、入库员（审核）、审计员（留痕） |
| 数据范围 | 农户本人行级；入库员本村行级 |
| 依赖 | 短信登录、`user_roles` 授权、云函数请求面 |

## 用户故事

作为农户，我希望用最少字段提交我的地块，并在审核通过后用于产品发布与溯源；作为入库员，我希望只审核本村数据，并能驳回不符合要求的地块。

## 验收口径（业务）

1. 农户提交合法地块后，状态为 `submitted`，不直接对外可见；
2. 入库员审核通过后状态为 `active`，版本号 +1；
3. 驳回必须填写原因，农户可修改后重新提交；
4. 同一幂等键重复提交不产生重复记录；
5. 非入库员/管理员不能审核；非本村入库员不能审核他村数据；
6. 版本号不一致时拒绝写入，提示刷新重试。

## 监测目标

每次提交与审核产生审计事件，包含 `eventId/type/occurredAt/actorUid/traceId/payload`；可按 `traceId` 串联一次请求。

## 部署目标

- 目标运行形态：CloudBase 云函数（范围 A），`event.action` 路由；
- 本地预演使用内存适配器，验证逻辑与契约；
- 正式实现替换为 PostgreSQL 适配器，不改变用例与测试。

## 架构规范

- schema 先行：Zod 严格校验，未知字段拒绝；
- 函数式：`domain/application` 纯逻辑，I/O 在 `adapters`；
- 接口边界：云函数内部不使用 REST 路径；HTTP 仅未来外部适配；
- 测试先行：用例先定义，覆盖正常/异常/越权/并发/幂等。

## 不在本期范围

- 地块地图与面积测绘；
- 土地权属证明上传；
- 与上级农业农村平台对接；
- 真实农户批量导入。
