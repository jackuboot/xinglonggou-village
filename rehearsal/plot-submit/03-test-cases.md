## 三、AI 评测用例

- 预填结果必须 `needsConfirmation: true`，且工具无写库能力；
- 低置信度（<0.5）时 UI 应提示补录，不允许直接提交；
- 预填只作为草稿，最终提交仍走 `submitPlot` 校验。
