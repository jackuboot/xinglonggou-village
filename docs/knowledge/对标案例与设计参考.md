## 六、对兴隆沟村的启示（摘要）

1. **文化域**：先做标准化编目（资源编号、授权状态），再谈数字馆与导览；
2. **适老化**：语音入口 + 村级协理员代操作，比单纯做 App 更现实；
3. **农业 AI**：验收指标不追实验室精度，按 Top-3 召回与专家复核一致率设定；
4. **交易**：先接帮扶/团购渠道，再图市场化撮合；批次与质检是底层前提。
