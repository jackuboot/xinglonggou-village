# 兴隆沟村平台战略基线（v0.1，待确认）

> 定位：这不是最终战略，而是一份**可讨论、可修改、可验收**的战略基线。  
> 作用：给蓝图、规则、预警、Agent 和预算提供方向与约束；没有战略挂靠的规则、指标和功能，不应该进入生产。  
> 状态：建议稿。带「待确认」的条目需要村委、项目负责人、农户代表和审计共同拍板。

## 0. 一句话

> 让农户多赚钱、让消费者吃得放心、让村集体有可持续收入，同时让平台自己活得下去。

这句话不是口号，它决定了后面的排序：

- 农户不赚钱，供给会消失；
- 消费者不放心，需求会消失；
- 村集体没有收入，公共服务不可持续；
- 平台不赚钱，前面三件事都撑不久。

## 1. 使命、边界与红线

### 1.1 使命

用数字化的服务和有边界的 AI，降低乡村资源整合、流转、交易和监管的成本，让农户、消费者、村集体和运营团队都能持续受益。

### 1.2 业务边界（先做什么，不做什么）

**先做：**

- 一个村、少数品类、可追溯的农产品；
- 农户提交 → 审核/质检 → 入库/上架 → 消费者购买 → 履约 → 审计；
- 面向老人的方言语音和低门槛交互；
- 村集体可管理的轻量平台，而不是全国性电商。

**暂时不做：**

- 一开始就做全品类、全区域、全链路自营；
- 用补贴换规模、用规模掩盖单位经济亏损；
- 无边界地让 Agent 自动做资金、定价、合规决定；
- 把未验证的模型结论当成事实或对外承诺。

### 1.3 红线

- 食品安全；
- 法律与政策合规；
- 农户尊严与自愿；
- 数据隐私与最小必要；
- 资金安全与不挪用；
- 不伪造检测、产地、资质和溯源信息。

红线不参与“利润 vs 成本”的权衡，一票否决。

## 2. 利益相关者与价值交换

| 对象 | 给我们什么 | 我们给什么 | 主要风险 | 话语权/申诉 |
| --- | --- | --- | --- | --- |
| 农户 | 货物、信任、履约 | 收购/代销、回款、技术服务、可追溯 | 价格波动、滞销、压价 | 农户代表、申诉 |
| 消费者 | 订单、复购、口碑 | 安全、溯源、稳定供应、售后 | 质量、虚假溯源 | 投诉、退款、评价 |
| 入库员/运营 | 劳动、专业、执行 | 工资、培训、安全、工具 | 忙闲不均、责任不清 | 运营负责人 |
| 村集体 | 场地、协调、信用、公共服务 | 分红、就业、服务、数据 | 政策、声誉、债务 | 村委/理事会 |
| 政府/监管 | 政策、基础设施、监督 | 合规、就业、乡村振兴 | 政策变化、检查 | 监管沟通 |
| 平台/运营方 | 资金、系统、管理 | 效率、透明、可持续 | 投资回收、现金流 | 董事会/理事会 |
| 审计/公众 | 监督、信任 | 可审计、可解释、可申诉 | 失真、滥权 | 独立审计 |

**原则：** 农户不是“流量”，而是长期合作者/共同所有者；消费者不是“转化率”，而是食品安全与信任的受托方。

## 3. 目标与默认排序

### 3.1 默认排序（不是永恒教条）

```text
1. 红线：食品安全 / 法律 / 农户尊严 / 数据隐私 / 资金安全
2. 生存：现金流、避免破产、关键供应、核心团队
3. 信任：农户收入、消费者安全、履约质量、社区关系
4. 单位经济：毛利、履约成本、损耗、回款周期
5. 学习与复制：标准化、培训、数据、可复制能力
6. 增长：村数、品类、订单、用户
7. 利润/盈余分配：再投资、农户分红、村集体、团队
```

### 3.2 为什么不是“利润第一”

- 利润是结果，也是燃料；没有利润，使命不可持续；
- 但把利润放第一，容易牺牲质量、农户利益和长期能力，最后反噬利润；
- 乡村平台的信任建立慢、毁掉快，一次质量事故可能抵消多年增长。

### 3.3 为什么不是“农户第一”或“消费者第一”的口号

- 农户、消费者、员工、村集体、平台是相互依赖的；
- 单边最大化会挤压另一方，最终不可持续；
- 正确做法是写清楚交换关系和风险分担，而不是喊口号。

## 4. 商业模式与单位经济（假设，待验证）

### 4.1 收入来源（建议组合，不能只靠补贴）

1. 交易服务费/佣金：按成交额收取，费率待确认；
2. 增值服务：包装、分拣、冷链、溯源、代运营；
3. 文化与文旅服务：村史、非遗、研学、导览；
4. 政府/村集体购买服务：公共服务、数字治理、就业；
5. 会员/订阅（谨慎）：农户或消费者增值服务，不搞强制。

**原则：** 补贴是启动燃料，不是商业模式；至少有一条收入不依赖补贴。

### 4.2 成本结构

- 采购/代销成本；
- 分拣、包装、冷链、物流；
- 运营人员、村级协理员；
- 技术与模型调用；
- 质量检测、合规、审计；
- 获客与内容；
- 损耗、退货、售后。

### 4.3 单位经济指标

| 指标 | 说明 | 初始目标（示例，待定） |
| --- | --- | --- |
| 单笔贡献毛利 | 收入 - 直接变动成本 | > 0 |
| 农户净收入 | 扣除成本后的实际收入 | 可对比传统渠道 |
| 损耗率 | 分拣/运输/存储损耗 | 逐季下降 |
| 履约成本/单 | 分拣+配送+售后 | 逐季下降 |
| 复购率 | 消费者重复购买 | 逐季提升 |
| 回款周期 | 农户多久拿到钱 | 明确承诺并遵守 |
| CAC / LTV | 获客成本/生命周期价值 | LTV > CAC，回收期可控 |
| 现金 runway | 现金能撑多久 | ≥ 12 个月（示例） |

## 5. 风险胃口与波动预算

### 5.1 风险容量

- 最坏能亏多少？
- 现金能撑几个月？
- 哪些错误不可逆？
- 哪些群体不能承受代价？

### 5.2 波动预算（示例，待确认）

| 项 | 建议约束 |
| --- | --- |
| 现金 runway | ≥ 12 个月 |
| 单月最大亏损 | 不超过可承受上限 |
| 客户集中度 | 单一大客户 ≤ 30% |
| 单品/单村集中度 | 有上限，避免一损俱损 |
| 农户政策影响面 | 单次 ≤ 10%，提前沟通 |
| 质量安全 | 零容忍，不设波动预算 |
| 试验预算 | 5%–10% 资源 |
| 营销波动 | 有上限，不靠烧钱换规模 |

### 5.3 可逆优先

- 先试点一个村、一个品类、一个渠道；
- 设阶段门禁：达标才加码；
- 设停止条件：亏损/投诉/质量达到线就停；
- 保留退出、转向、延期的权利；
- 不用全部身家赌一个判断。

## 6. 治理与决策权

### 6.1 治理结构（建议，待确认）

- **村委/理事会**：战略方向、红线、预算、分配；
- **农户代表**：价格、回款、服务、申诉；
- **平台运营团队**：日常经营、技术、履约；
- **审计/合规**：独立复核、规则与资金审计；
- **外部专家**（必要时）：农技、法律、财务。

### 6.2 决策权表

| 决策 | 提议 | 评审 | 批准 | 知会 |
| --- | --- | --- | --- | --- |
| 日常运营 | 运营负责人 | 财务/质量 | 总经理 | 团队 |
| 农户政策/价格 | 运营 + 农户代表 | 财务/村委 | 理事会 | 农户 |
| 重大投资 | 业务负责人 | 财务/技术/审计 | 董事会/理事会 | 村集体 |
| 红线/合规 | 合规负责人 | 审计 | 理事会 | 监管 |
| 规则/阈值变更 | 规则所有者 | 业务/审计 | 治理委员会 | 受影响方 |
| 盈余分配 | 财务 | 审计/农户代表 | 理事会 | 全村 |

### 6.3 原则

- 提议、评审、批准分离；
- 能本地决定的，尽量本地决定；
- 受影响方有申诉渠道；
- 高风险、不可逆的决定，必须有人类签字；
- 价值冲突不靠模型裁决，靠合法程序。

## 7. 阶段战略

| 阶段 | 目标 | 优先级 | 关键指标 | 门禁 |
| --- | --- | --- | --- | --- |
| 0 验证 | 证明有人愿意买、有人愿意供 | 生存 > 信任 > 学习 | 首批农户、首批订单、履约率、现金 | 有复购、无重大质量事故 |
| 1 单村密度 | 一个村/一个品类做透 | 信任 > 单位经济 > 增长 | 复购、损耗、毛利、农户收入 | 贡献毛利为正、服务稳定 |
| 2 多村复制 | 复制 playbook | 单位经济 > 学习 > 增长 | 复制周期、培训合格率、单村盈亏 | 新村干部/团队可独立运营 |
| 3 区域网络 | 数据、金融、服务、渠道网络 | 网络效应 > 单位经济 > 增长 | 合作伙伴、留存、take rate | 不靠补贴也能转 |
| 4 韧性 | 抗冲击、接班、政策变化 | 生存 > 合法性 > 增长 | 现金、集中度、接班、恢复 | 通过压力测试 |

每个阶段都要重新审议目标权重，不要用 Stage 0 的指标管 Stage 3。

## 8. 战略到规则的映射

| 战略选择 | 规则表现 | 例子 |
| --- | --- | --- |
| 食品安全红线 | 硬阻断、人工复核 | 检测缺失不允许自动上架 |
| 现金流优先 | 止损线、升级线 | 亏损/回款超限触发高优先级 |
| 农户信任优先 | 价格/回款/申诉规则 | 不得静默压价、逾期回款告警 |
| 单村密度阶段 | 质量/复购规则优先 | 不奖励盲目扩张 |
| 风险胃口低 | warn 更早、critical 更严 | 阈值从宽改严 |
| 分权治理 | scope 清晰 | 本村规则只在本村生效 |

每条规则在注册表里必须有 `strategyRefs`，指向它服务的战略目标、红线或风险预算。  
**没有战略挂靠的阈值，只是拍脑袋。**

## 9. 待确认决策

1. 法律主体：村集体合作社 / 强村公司 / 社会企业 / 混合？
2. 收入结构：佣金费率、增值服务、政府购买服务各占多少？
3. 盈余分配：再投资、农户分红、村集体、团队的比例？
4. 首批品类与村：先做哪 1–2 个品类、哪 1 个村？
5. 风险胃口：现金 runway、单月最大亏损、农户影响面、试验预算的具体数字？
6. 治理结构：谁有否决权？农户代表怎么产生？审计向谁负责？
7. 数据权属：农户数据、交易数据、村集体数据归谁？如何授权？
8. 阶段目标：Stage 0/1/2 的具体营收、复购、毛利、农户收入目标？

这些不确认，战略就还是口号；规则和预算也会继续拍脑袋。

## 10. 90 天战略工作

**第 1–2 周**

- 开一次战略基线会：确认使命、红线、利益相关者、待确认决策；
- 盘点现金、集中度、质量、政策风险；
- 找当前最大瓶颈。

**第 3–4 周**

- 确认默认目标排序和阶段目标；
- 设风险预算和试验预算；
- 明确决策权、申诉和审计。

**第 2 个月**

- 做一次单位经济基线：单笔贡献毛利、损耗、履约成本、回款周期；
- 选 1–2 个可逆试验，设成功/停止条件。

**第 3 个月**

- 开治理会：确认/调整战略基线；
- 回写蓝图与 PPT；
- 给规则加 `strategyRefs`；
- 设 Stage 0 → Stage 1 门禁。
