# AI 技术雷达与采纳清单（v0.1）

> 判断标准：是否卡住 P0 场景；是否增加不可控复杂度；是否有明确触发条件。只把真正解决问题的技术纳入架构。

## 一、现在就纳入（按阶段实现）

| 技术 | 解决什么问题 | 融入位置 | 复杂度 | 验收 |
| --- | --- | --- | --- | --- |
| **Agent 可观测与评测** | Agent 是黑盒，错了不知道错在哪 | 运行面 + 监测点：OpenTelemetry GenAI 语义约定、trace、golden set、RAG 指标 | 中 | 每个任务可回放；评测报告可对照 |
| **混合检索 + 重排 + 引用** | 纯向量检索对政策/农技术语不准 | RAG：PG 全文检索（BM25 思路）+ pgvector + rerank + 强制引用 | 中 | 检索命中率、引用率达标 |
| **文档 AI（OCR/版面/表格）** | 政策、农技资料是 PDF/扫描件，进不了知识库 | 知识入库管道：腾讯 OCR / PaddleOCR / MinerU 类能力 | 中 | 主要政策能结构化入库 |
| **Agent 安全护栏** | 提示注入、工具投毒、越权调用 | 工具网关：能力令牌、白名单、沙箱、输入输出审查 | 中 | 红队用例被拦截并留痕 |
| **事件可靠性模式** | 重试导致重复扣库存/重复通知 | 运行面 + 事件总线：幂等键、事务性发件箱（outbox）、CloudEvents 信封 | 低–中 | R-03 故障恢复无重复副作用 |
| **结构化输出** | 工具调用参数解析失败、格式漂移 | 全部工具：JSON Schema/Zod + function calling + 约束解码 | 低 | 工具调用解析成功率 ≥99% |
| **成本治理** | Token 与调用成本不可控 | 模型网关：预算、分级路由、缓存、降级 | 低 | 单会话成本有基线，超预算告警 |

> 结构化输出与 Zod 已在工程规范中；这里是把"约束解码/工具 schema"补齐到模型网关。

## 二、条件采纳（有触发再做）

| 技术 | 触发条件 | 目标阶段 |
| --- | --- | --- |
| Temporal / Restate 类持久执行引擎 | 工作流跨天、跨服务，人工中断频繁，现有检查点不够 | P2 |
| 知识图谱 / GraphRAG | 政策、文化关系问答成为 P1 需求，普通 RAG 解释力不足 | P2 |
| 实时语音到语音、打断 | 语音问答上线后，老人使用数据证明需要更自然的对话 | P1–P2 |
| 离线/边缘推理 | 弱网或"数据不出村"成为硬约束 | P2 |
| 合成数据 + 主动学习 | 本地病虫害 Top-3 <85% 且采集速度跟不上 | P1 |
| 专用向量数据库 | 知识块 >10 万，或检索 P95 >300ms | P2 |
| A2A（Agent-to-Agent） | 出现跨村、跨系统 Agent 协作需求 | 观察 |
| TEE / 机密计算 | 第三方模型必须处理敏感数据且无法脱敏 | 观察 |

## 三、观察，不纳入当前架构

- A2A 协议、computer-use Agent、实时语音到语音、TEE；
- 多 Agent 蜂群/群体智能；
- Agent 市场与插件生态。

观察项每季度复盘一次，不进入当前设计文档的强制要求。

## 四、明确不采纳

| 技术 | 不采纳理由 |
| --- | --- |
| 自研基础大模型 | 成本、数据、周期不划算；现成模型 + RAG 足够 |
| 区块链溯源 | 中心化数据库 + 审计留痕已满足；链增加复杂度 |
| 联邦学习 | 当前数据规模与隐私要求未到 |
| 特征商店 / 湖仓 | S1 规模用不上，增加运维面 |
| 多 Agent 蜂群 | 没有评测集之前，Agent 越多越不可控 |
| 无边界自动化 | 与"人在回路"原则冲突 |
