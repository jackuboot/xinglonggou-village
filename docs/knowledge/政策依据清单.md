## 二、数据与 AI 合规（按名称引用，原文以官方发布为准）

- 《中华人民共和国数据安全法》——数据分类分级、重要数据保护；
- 《中华人民共和国个人信息保护法》——最小必要、告知同意、敏感个人信息保护；
- 《生成式人工智能服务管理暂行办法》——生成内容标识、训练数据与安全评估要求（适用时）。

> 涉农数据的行业细则与地方规定需在落地前由合规负责人补充核对，不能仅凭本清单作出合规结论。

## 三、使用约定

1. 政策问答类 Agent 必须引用本清单中的原文条目，并在回答中给出处；
2. 摘要与原文冲突时以原文为准，摘要需及时修订；
3. 政策更新由知识管家 Agent 定期巡检（建议每月一次），发现失效链接或新版本时提醒人工复核。
