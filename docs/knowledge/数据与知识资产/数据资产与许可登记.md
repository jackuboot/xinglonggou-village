## 二、资源与服务数据：农户自助提交（ToC 设计）

**原则**：不做事前集中采集；农户注册后按需提交，系统用最小字段启动、渐进完善、审核后生效。

提交与校验闭环：

1. **注册即用**：短信登录后只要求村组、地块面积、主要作物三项最小信息；
2. **降低门槛**：语音转写、拍照识别预填、协理员代办模式，照顾老人；
3. **提交草稿 → 审核生效**：入库员/审计员核验后进入业务库并对外可见；
4. **渐进完善**：发布、订单、溯源等关键动作前再补齐必要字段，不一次性要求全部资料；
5. **激励闭环**：资料完整、核验通过的农户优先获得发布位、订单与内容曝光。

关键指标：提交完成率、首次提交耗时、核验通过率、资料完整度、周活跃提交农户数。这些是增长与运营指标，不是项目前置门禁。

## 五、标注规范（病虫害照片）

每条样本至少包含：图像编号、作物、拍摄部位、病害/虫害类别、严重度、拍摄环境（田间/室内）、村组、拍摄时间、标注人、复核人。禁止包含人脸、门牌号等可识别个人信息；原图与标注文件分离存放。

## 六、许可与使用边界

1. 外部数据集只用于训练与评测，不对外二次分发；
2. 学术许可不等于商用许可，上线前逐项确认；
3. 农户提交的照片、语音、故事需在提交时告知用途并取得授权；
4. 第三方模型调用前评估数据出域与留存政策；
5. 所有语料保留出处，引用时能回溯。

## 七、保留与访问

- 敏感数据加密存储，界面脱敏展示；
- 审计日志只增不改，按监管要求保留；
- 数据导出需审批并记录用途；
- 用户可申请更正或删除其提交的数据。
