# 度量指标与反馈闭环（v0.1）

> 目的：让"有没有用"可度量、可复盘、可迭代，而不是靠感觉判断。

## 二、反馈渠道

1. 村级协理员：日常收集农户问题与不满；
2. 农户访谈：每月抽样 5–10 户；
3. 系统内"结果不对"按钮（待开发）：一键上报错误答案与图片；
4. 审计抽检：验证 Agent 操作与知识引用；
5. 订单/服务纠纷记录：反映流程与质量问题。

## 三、闭环流程

反馈 → 归类（知识缺口 / 模型错误 / 流程问题 / 产品缺陷）→ 指派处理人 → 修复 → 更新知识条目或评测集 → 回访确认。

## 四、复盘节奏

| 频率 | 会议 | 输出 |
| --- | --- | --- |
| 每周 | 运营例会 | 反馈清单、阻塞项更新 |
| 每月 | 指标复盘 | 指标趋势、知识缺口、模型效果 |
| 每季度 | 阶段门禁评审 | 是否进入下一阶段、是否调整范围 |

## 五、责任分工

| 角色 | 职责 |
| --- | --- |
| 产品 Owner | 指标定义、复盘主持、决策 |
| 知识管家 | 知识缺口处理、条目更新 |
| AI 工程师 | 模型评测、错误分析、降级处置 |
| 审计员 | 留痕核查、隐私事件复核 |
| 村级协理员 | 反馈收集、回访 |

## 六、当前状态

- 所有指标尚无基线，属于"定义完成、数据为零"；
- 首个基线将在 P0 评测（50–100 张照片、20–30 个问题）后建立；
- 反馈渠道中只有线下访谈可用，系统内上报入口待开发。
