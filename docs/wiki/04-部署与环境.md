## 部署流程

| 子项目 | 命令 | 过程 |
| --- | --- | --- |
| 官网 | `powershell -ExecutionPolicy Bypass -File web/deploy.ps1` | `node scripts\build.js` → 部署 `dist/` 到官网子路径 → 追加部署 `robots.txt` 到域名根（失败不阻塞） |
| 工作台 | `powershell -ExecutionPolicy Bypass -File dashboard/deploy.ps1` | `npm run build` → `tcb hosting deploy dist /app` → 交互式设置首位超管（回车可跳过） |

前置依赖：本机已安装 Node.js、已登录 CloudBase CLI（`tcb`），云函数 `roles-admin` 需先部署到环境（`cloudfunctions/roles-admin/`）。

## dashboard/scripts/ 工具清单

| 脚本 | 用途 |
| --- | --- |
| `set-super-admin.mjs` | 设置首位超级管理员（bootstrap，用法 `node scripts\set-super-admin.mjs <手机号>`）。注意：脚本内 tcb CLI 路径硬编码为 `C:/Program Files/nodejs/...`，换机或 npm 全局路径不同会导致失败；手机号须先在应用登录过一次（用户目录才存在该用户） |
| `test-auth.mjs` | 认证链路测试 |
| `check-local.mjs` | 本地环境检查 |
| `diag-live.mjs` / `diag-stack.mjs` / `diag-interact.mjs` / `close-probe.mjs` | 线上诊断 / 技术栈探测 / 交互诊断 / 探针关闭 |

## 本地开发

- 工作台：`dashboard/` 下 `npm install` 后 `npm run dev`（Vite）。
- 官网：改 `web/content/site.json` 后 `web/preview.ps1` 或 `node web/scripts/serve.cjs` 预览。
